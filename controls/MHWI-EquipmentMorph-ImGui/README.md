## 使用

1. 在游戏获得焦点时按 **Del** 呼出；非文本编辑时再次按下请求结束预览并关闭。文本框编辑期间 Del 用于正常删除文字，可用面板 × 关闭。旧 Ctrl＋Shift＋M 不再使用。
2. 下拉选择当前已绑定、具有形态键数据的装备部位。列表来自核心 API，不列出未穿戴／尚未绑定的模型，也不替玩家换装。
3. 每行四列为 **形态键 | 目标权重 | 精确输入 | 实际权重**。拖动滑块即时提交；输入框按回车提交。仅查看装备不会接管权重；选择预设会立即预览匹配部位。
4. 修改一个键即接管该键；名称前的勾选表示本面板是否持有贡献。取消勾选仅释放这一键；“启用捏人”关闭后释放本面板全部贡献，并阻止预览、调节及自动恢复。
5. 快捷键和面板 **×** 请求结束预览：有修改时提供“保存并关闭”“放弃并关闭”和“取消”，恢复各部位已保存的穿戴默认成功后才隐藏。没有匹配默认的部位释放本面板临时控制。失去焦点和最小化仅临时隐藏并保留编辑，不作为结束预览。总开关关闭时仍可管理预设；关闭窗口不会重新开启捏人。开关状态跨重启保留，重新开启后恢复已应用预设。其他来源保持独立，形变沿核心既有平滑流程恢复。

精确输入保留 float32 的 9 位有效数字；滑块与实际权重统一显示 3 位小数，不据此量化提交或保存值。最后一列读取核心的 **已应用权重**，因此平滑时可能与编辑值暂时不同；悬停仍可查看 9 位有效数字的请求／实际值及是否有其他来源优先。无效／越界输入和互斥冲突会显示错误，并保留此前已接受的贡献。

主面板选中预设即临时预览匹配部位，不修改穿戴默认关联；“保存当前”只更新当前编辑预设的部位，保留其未穿戴部位的数据，不混入其他预设的权重。修改不自动写文件；切换预设、关闭捏人或关闭主窗口前有未保存修改时，可保存、放弃或取消。保存非默认预设后关闭仍恢复原默认，只有“应用预设／取消应用”改变关联。另存为则捕获本面板全部已接管部位。管理窗口的列表选择仍只查看文件。每次游戏启动使用默认位置与尺寸，不保存布局；本次游戏内仍可拖动和调宽。

保存预设后点击“应用预设”，注册其各部位的精确模型与形态键包关联；同一模型已有的关联被替换，其他模型和部位保留。启动和换装时由后台按部位恢复已保存版本，不需要先打开窗口。只更换腰部不会覆盖身体的实时编辑；未保存修改和旧目标排队命令不会重放到新目标。“取消应用”只取消以后自动使用，当前预览效果保留至关闭或换装；需要停用本面板形变时关闭“启用捏人”。来源租期意外失效时丢弃旧草稿，重新匹配已保存默认。

## 安装与回滚

需要 Windows x64、DX12 模式和 Stracker's Loader。正常退出游戏后，将配套构建的 `MHWEquipmentMorphConfiguredPrototype.dll` 与 `MHWEquipmentMorphImGui.dll` 放入 `nativePC/plugins/`，保留 `runtime.ini` 与装备资产。旧核心搭配新面板仍可调节权重，但没有身份扩展时不能使用预设。不需要外部 EXE、Tauri、WebView2 或控制桥接。

本阶段只替换 GUI DLL，不重建或替换已测试核心。回滚时正常退出游戏后恢复 GUI 备份；预设、`auto-presets.json` 和新增的 `panel-settings.json` 可保留。上一版 GUI 支持自动关联但不识别新的持久总开关，回滚后按旧版逻辑自动使用预设；需要完全停用本面板时可移除 GUI DLL。自动使用位于可选 GUI DLL 的普通后台线程：移除 GUI 会同时停用面板及穿戴默认，核心仍可由其他插件通过公开 API 使用。许可证随源码／候选文件保留，不重新分发系统字体。

## 构建与非界面验证

在仓库根目录运行：

```powershell
./tools/build_mhwi_equipmentmorph_imgui.ps1
```

默认输出 `.build/current-validation/imgui/`，可用 `-OutputDirectory` 指定目录。使用现有 MSVC／Windows SDK，不重建／安装核心。脚本编译 DLL、历史软件窗口程序，以及无窗口的 `ImGuiControlTests.exe` 和 `ImGuiPresetTests.exe`，**只执行输入策略、控制与预设的控制台测试**。输入策略回归检查 Del／文本编辑分流、IME 消息分类、跨线程平台请求合并及游戏边界计算，不创建窗口或执行真实输入法操作。33 项控制回归覆盖接口校验、命令合并、贡献隔离、实际应用值、冲突拒绝、隐藏续租、目标替换、释放取消排队编辑、租期过期、并发发布、float32 精度、快速实际权重读回、隐藏降频及换装发现。预设回归另覆盖筛选、管理、永久删除、部分失败、管理栏边界，以及启动自动使用、部分换装、未保存切换、按编辑来源保存、暂停／恢复、只读配置失败、无效自动配置重试，以及关闭预览的恢复默认、保存／放弃、排队编辑、恢复失败和其他来源隔离；本阶段另覆盖总开关持久化、禁用后的排队命令、配置写入失败／损坏，以及装备名称和完整资源编号。名称表在构建时从现有装备目录生成并编入 DLL，游戏中不额外读取目录文件。呈现和操作手感仍由用户验证。

## 运行方式与日志

- 可选 DLL 使用已验证的窗口、输入及 DX12 路径。支持插件加载时交换链已存在；优先使用创建时队列，或从后台缓冲最终转换与命令提交识别渲染队列。特殊跨队列呈现／交换链包装兼容性仍以实机为准。
- 权重 API 只由普通后台线程调用。渲染与输入线程交换不可变快照和合并后的编辑命令，不直接枚举目标或提交权重。装备与键元数据约每 250ms 扫描；显示时约每 16ms 合并处理输入并读回已应用权重，快速读回不重复枚举装备与键。隐藏时停止快速读回，继续低频扫描和续租。会话复用现有控制会话逻辑，优先级 220、租期 2000ms。
- 隐藏时跳过 ImGui 帧与 GPU 提交，后台匹配及续租继续。渲染／窗口故障只停用界面，后台自动使用继续；控制线程故障请求释放并暂停自动使用。其他来源的贡献保持独立。
- Del 只在游戏拥有焦点且面板文本框未编辑时注册；文本编辑／失焦时解除注册。热键本身不处理输入法转换键。面板文字编辑使用独立 IME 上下文，窗口线程接受系统语言切换、处理原生组合文本并把提交字符交给 ImGui；停止编辑或隐藏后恢复游戏原上下文。仅在文字编辑的 TranslateMessage 调用中绕过本插件键盘查询屏蔽，普通游戏查询仍受捕获约束。手柄和 GetRawInputBuffer 尚未接入。
- 日志：`nativePC/plugins/MHWEquipmentMorph/logs/imgui-<PID>.ndjson`。本阶段标记为 `stage=11`，`preset_count`、`usable_presets`、`recycled_presets` 分别记录总数、有匹配部位的数量与回收区数量；`default_links`、`auto_paused`、`auto_message`、`editor` 记录自动关联数、暂停状态、自动错误及当前编辑编号，`preview` 表示临时预览／编辑状态，`morph_enabled` 记录持久开关；旧 `auto_paused` 仍用于临时故障隔离诊断。正常为 `boot=1`、`error=none`、`window_ready=true`、`queue_ready=true`，快捷键注册为 `hotkey_registered=true`、`hotkey_error=0`。
- 接口字段：`api_connected`、`control_ready`、`targets`、`source`、`control_result`、`snapshot_result`。只查看时 `source=0`；接管后为本面板来源，释放后回到 0。错误码沿用公共 API。
- 依赖为固定 Dear ImGui v1.93.0，来源及逐文件摘要见 [UPSTREAM.json](../../research/imgui-v1.93.0/UPSTREAM.json)。系统字体使用 `msyh.ttc`，不重新分发字体。

历史快速响应候选：配套核心将临界阻尼参数由 `omega=8` 调整为 `80`，理想阶跃约 59ms 达到 95%、83ms 达到 99%；保留速度连续性、边界约束、原有约 16ms 网格采样及 GPU 资源协议。这会影响核心接收的所有来源权重，并非仅面板滑块。面板显示仍读取核心确认值，不预测或替换实际值。

上述响应候选当时配套更新核心与 GUI；本阶段只更新 GUI，沿用已部署核心。单独运行上述面板构建脚本只生成 GUI，不会构建或替换核心；核心构建入口为 `tools/build_mhwi_equipmentmorph_current.ps1`。

拖动主面板时窗口矩形限制在游戏视口内，左键按住期间鼠标限制在游戏客户区，松开／失焦后解除临时约束。原生光标更新和 IME 关联、候选位置更新均由窗口线程执行；渲染线程只发布合并请求，避免持有界面锁时同步调用这些系统接口。上述阻塞风险来自代码检查；已有日志未捕获可对应这次反馈的完整停顿，不能据此确认唯一根因。

## 本轮用户测试

2026-10-22 发布前审查修复候选补充读取失败时的草稿保护、批量文件操作后的租期恢复和回收区异常隔离。新增控制台异常回归；本修复候选尚待用户实机确认。常规复测重点为预览、保存与关闭确认，以及导入／导出／回收管理；无需在实机人为制造读取失败或租期失效。

- Del 呼出／关闭、长按不反复切换；编辑名称和搜索文字时 Del 删除字符，× 仍可关闭。旧组合键不再触发面板。
- 多显示器下拖动主面板至游戏四边，松开后仍可操作；确认无约 10 秒停顿。失焦、最小化和改变游戏大小后鼠标约束正常释放。
- 在保存、重命名和搜索文本框切换中文输入法，验证拼音、候选选择、中文提交和中英切换；隐藏／再打开后继续编辑。
- 以下已通过的预设功能作必要回归：

- 对 D 点击“应用预设”，依次选中 A、B，模型即时预览对应参数；× 和快捷键关闭后均恢复 D。保存 B 不改变默认关联。
- 保存后点击“应用预设”，重启游戏且不打开面板，确认形变自动恢复；切走再穿回时恢复已保存值。
- 多部位关联不同预设，只换一个部位，其他部位实时编辑保留；保存当前不混入其他预设。
- 编辑 B 后关闭，验证保存并关闭、放弃并关闭和取消；保存只更新 B，关闭仍恢复 D。没有匹配默认的部位释放临时控制。
- 关闭“启用捏人”后禁用预览／调节，换装、关闭窗口和重启均不恢复本面板形变；重新开启恢复已应用预设。其他插件的控制独立。
- 关闭开关时有编辑，验证保存、放弃和取消；保存失败保留编辑。关闭状态仍可管理预设。
- 取消应用、回收及恢复文件不意外重启自动关联；重启恢复默认窗口布局。
