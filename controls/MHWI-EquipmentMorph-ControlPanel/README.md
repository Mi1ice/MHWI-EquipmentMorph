# MHWI-EquipmentMorph · 手动形态键控制 0.1.0

这是独立的 Windows x64 控制窗口，通过公共 C API 的同进程桥接插件使用装备形态键运行时。依赖 Stracker's Loader 以及 `MHWEquipmentMorphConfiguredPrototype.dll`；无需 SharpPluginLoader。形态键资产由作者工具另行生成。本包不含任何 MOD、模型、测试形态键载荷或自动表情功能。

## 安装与使用

1. 正常退出游戏。把 `MHWEquipmentMorphControlBridge.dll` 放入游戏的 `nativePC/plugins`，保留已安装的运行时及其配置。
2. 启动游戏，使已配置装备出现在人物身上。自动绑定运行时不需要 F8；不兼容或未配置的部位不会出现在窗口中。
3. 双击 `MHWI-EquipmentMorph-ControlPanel.exe`，普通权限运行，与游戏使用相同的 Windows 用户。窗口可以先于游戏打开，会自动等待连接。
4. 选择装备和形态键。输入范围内的连续数值，点击“设置”即可接管当前键；或勾选“接管当前形态键”后拖动滑块。滑块分为1000步，数值框接受任意有效 float32 权重，显示9位有效数字。
5. 取消当前键的接管，只释放这个键。“释放全部控制”释放此窗口的全部贡献，关闭窗口也会释放。释放后由其他控制来源接管；没有其他来源时回到基准形态。

表格的“目标权重”是接口当前请求；“已应用”是运行时已发布的权重，平滑过程中会暂时不同。独立部位的发布不保证在同一帧完成。数值框显示本窗口自己的贡献；更高优先级来源胜出时，表格会注明。

权重0仍属于显式接管，可覆盖低优先级来源；“释放”才交回控制。多个已接管键在修改其他键时保持。互斥键冲突或无效输入不会覆盖原贡献；窗口显示接口结果，0成功、1输入无效、2目标/来源失效、3容量不足、4互斥冲突、5尚未准备好、8内部错误。

## 连接和生命周期

桥接只调用公开接口，不设置Hook、不读取游戏对象、不提交GPU命令。窗口只枚举游戏进程并连接本机命名管道，核对管道服务进程ID。只支持同一用户的一次游戏运行、一个控制窗口；多游戏实例时暂停连接。桥接拒绝远程客户端。

控制来源优先级220，租期2000ms。窗口每250ms查询状态；桥接在断开连接时立即释放，1500ms未收到有效请求时主动释放，租期提供后备清除。界面失去响应时网络线程不自行续租。关闭窗口后运行时会沿现有平滑/缓冲流程恢复，因此释放请求与最终恢复画面不是同一瞬间。

换装或场景重建时自动重新列出目标；新目标不继承旧权重，连接丢失后也不重放操作。未失效部位的接管会保留。窗口不保存预设、工程或权重，不调整装备，不改动存档。

卸载：正常退出游戏后移除本包安装的桥接DLL和窗口文件。不要移除其它插件或作者的原MOD。
