# 整套形态键预设（开发候选）

需要支持身份查询扩展的核心和可选 Dear ImGui 面板。预设由面板管理，核心继续独立提供形态键 API。用户已确认第四／五阶段预设功能通过，第六阶段除希望增加调宽外其余项正常；第七阶段增加右侧拖动调宽和导入／导出，尚待用户实机测试，不改变正式发行。

## 保存与应用

1. 调节并接管所需部位的形态键。原有复选框继续区分“显式零权重接管”和“释放该键”。
2. 在窗口顶部点击“另存为…”，输入整套预设名称并保存。预设包含本面板已接管的所有部位与键，包括零权重；其他插件的贡献不写入。
3. 下拉框只列出整套全部匹配的预设，可按名称搜索。选择本身不改变权重，点击“应用”才会生效。换装导致原选择不匹配时保留其状态提示，不自动应用其他预设。
4. 修改后显示“已修改，尚未保存”。“保存”更新当前预设，“另存为…”创建另一份。浏览其他预设时先应用它，或另存为当前设置；“保存”只更新当前已应用／保存的预设。

保存记录已接受的目标权重，保留 float32 精度，避免把平滑中间值或其他优先来源的实际值保存下来。后台先处理保存之前排队的编辑，再保存；若该批编辑被拒绝，则保存失败并显示原因。输入框仍可按回车提交。

尚无面板贡献时不能保存空预设。勾选并设为零的键仍是有效贡献，可以单独保存。名称最多 128 个 UTF-8 字节，允许中文；同名另存为会提示更换名称。

## 筛选与管理

点击预设栏的“管理…”，或下拉框内的“管理全部预设”，在主面板右侧打开附随的游戏内管理栏。它随主面板移动、保持顶部对齐和相同高度；拖动右边缘可调整宽度，不能单独移动或改变高度。宽度受游戏画面边界限制，隐藏或关闭后再打开会保留本次会话的宽度，重启游戏恢复默认。靠近屏幕边缘时调整主面板位置，空间不足时缩小布局；特别窄的画面以内侧重叠方式保留可见入口。关闭管理栏后主面板保持当前位置和大小。下拉框没有可用项时，未匹配的预设仍可从此入口找到。

- “全部预设”列出有效预设；“回收区”列出已删除预设。两者均可名称搜索，并按全部、完全匹配、部分匹配、无匹配筛选。英文搜索忽略大小写，中文按原文匹配。
- 选择条目可查看所含部位、匹配结果和逐部位原因；可展开保存的权重及资产指纹。筛选和选择详情不改变当前形态键。
- “重命名”只修改文件中的名称，保留编号、装备身份和权重；当前预设名称同步更新。未保存的面板修改不会被重命名操作写入文件。
- “删除到回收区”将文件移入 `presets/.trash/`，不会释放或改变形态键控制。删除当前使用的预设后，当前配置标为未保存，可另存为新预设。
- “恢复”将文件放回预设列表，但不自动选择或应用。遇到同名预设时，先在回收区中重命名后重试；遇到相同编号的文件时拒绝覆盖。
- 回收区条目的“永久删除”会先显示名称和不可撤销提示，确认后仅删除该回收文件。“删除全部”同样需要确认，范围是整个回收区，包括被当前搜索或匹配筛选隐藏的预设；取消不执行删除。两者均不释放或提交形态键权重。

管理不要求当前穿戴匹配装备，也不要求核心已连接。关闭管理窗口只关闭该窗口；主面板快捷键隐藏时两者一起隐藏并保留控制，主面板“×”沿用释放本面板贡献并隐藏的行为。

回收区会在重启后保留。永久删除无法从面板恢复；文件不可写时保留文件并显示错误。批量删除逐项执行，部分失败时显示成功与失败数量，只移除成功项，可检查权限后重试。仅处理回收区根目录中编号合法的 `.json` 文件，也包括这类文件中损坏而未能显示的预设；非预设文件、链接和子目录不会被递归删除。文件移动失败、重命名保存失败或恢复冲突时保留原文件。只处理经过校验的预设编号，不接受显示名称作为文件路径。

## 导入与导出

继续使用 `schema: 1` JSON，一份文件保存一套预设。仅携带名称、编号、部位、资产指纹、形态键 ID 和权重，不含 MOD、贴图或运行时句柄。导入不转换 MOD 身份，应用仍需严格匹配。

导出：在“全部预设”中选择条目点击“导出”，或点击上方“导出全部”。导出全部包含正常列表的全部预设，不受搜索／匹配筛选影响，也不包含回收区。导出的是已保存内容；当前调节未保存时先保存或另存为。

每次导出在 `nativePC/plugins/MHWEquipmentMorph/exports/` 中创建带时间与独立编号的子目录，文件以预设编号命名，名称仍保存在 JSON 内。完成后显示目录、成功和失败数量；不覆盖以前的导出。批量逐项写入，失败时保留已成功导出的文件，显示错误原因。需要分享或备份时复制对应文件夹或其中的 JSON 即可，首版不处理 ZIP。

导入：

1. 将收到的 JSON 放入 `nativePC/plugins/MHWEquipmentMorph/imports/` 根目录。
2. 在“全部预设”点击“导入…”，面板在游戏内刷新预览；后续增删或修改文件后点击“刷新预览”。首次刷新会创建目录。
3. 勾选待导入项目，点击条目可查看文件名、部位／键数量和当前装备匹配情况，并编辑导入名称。可全选有效项或取消全选；无效文件列出原因且不能勾选。
4. 点击“导入勾选项”，查看新增、重复跳过和失败数量。无需重启；完成后不自动选择或应用，不改变当前控制和未保存状态。

预览只扫描根目录中的 `.json` 文件（扩展名忽略大小写），支持 UTF-8 和 UTF-8 BOM，不跟随链接或递归扫描文件夹。一次最多 256 个 JSON，单文件最多 256 KiB。预览已读取并校验文件，确认时使用该预览内容；源文件随后变化不会悄悄改变导入结果，需要刷新才能更新。

同名且内容相同的预设跳过；忽略内部编号及部位／键的排列顺序。名称相同而内容不同，默认建议“原名（导入）”或带序号的名称，允许修改，确认时再次检查。格式损坏、版本不支持、名称或权重无效、预览失效、库容量不足等会拒绝对应条目，其他有效条目继续导入；部分成功不会回滚成功项。源文件保持原样。

每份新导入预设生成新的本地编号并以不覆盖方式写入，不覆盖正常列表、回收区或相同编号的既有文件。当前装备不匹配或核心未连接仍可导入／导出；不匹配项在管理列表保留，正常预设下拉框继续只显示可应用项。

## 严格匹配

每个保存的部位同时核对：部位、模型资源路径、MOD3 的 SHA-256、形态键数据包的 SHA-256、形态键 ID 和权重范围。指纹来自核心启动时已校验并加载的资产，面板不在拖动或绘制时读取 MOD 文件。

- 同名装备替换了 MOD3，或同名形态键的数据包内容改变：不兼容。
- 缺少预设涉及的部位、尚未绑定、缺少键或无法读取已验证身份：不能应用。
- 预设未涉及的其他穿戴部位：不影响匹配。
- 仅更换贴图，模型和形态键数据包未变：仍可匹配。
- 换装后出现相同内容的新目标：重新匹配，但不自动应用。

全部校验通过后，用一次 API 批量提交替换本面板的完整贡献集合。旧集合中未被新预设包含的键随之释放；其他来源继续独立工作。批量被拒绝时不部分应用。各部位的实际网格仍沿现有独立发布和平滑流程更新，并不承诺同一个 GPU 帧同时切换。

## 文件与错误处理

文件位于游戏目录下 `nativePC/plugins/MHWEquipmentMorph/presets/`。保存成功时创建目录，每份预设为一个 JSON 文件，文件名使用独立编号，不使用显示名称作为路径。

JSON 格式版本为 `schema: 1`，含编号、名称及逐部位的身份、形态键 ID、权重。不保存运行时句柄和键索引，不包含模型或贴图。加载时重新解析当次有效目标；校验后发生换装时，核心会拒绝失效句柄。

文件读写在普通后台线程执行。写入临时文件并完成刷新后替换正式文件；保存失败保留旧文件。正常列表最多 256 份、回收区最多 1024 份，单文件不超过 256 KiB。损坏文件单独跳过并显示数量，重复字段、非法数值和不支持的版本会被拒绝。

首次启动和文件管理操作维护内存列表；匹配结果按目标身份与预设变更缓存，拖动滑块不重新匹配整个库或回收区。管理与导入列表仅绘制可见条目，不在绘制或权重读回时扫描磁盘。批量删除、导入／导出期间在文件操作间按约 500ms 为现有控制来源续租，不创建或重放权重。外部手动修改正式预设库后重启游戏以刷新；导入暂存文件由“刷新预览”重新读取。文件读写支持 Windows 长路径。部分应用、自动套用及跨 MOD 迁移暂未实现。

## 可选身份查询扩展

公开头文件为 [mhw_morph_identity.h](../runtime/EquipmentMorphPerKeyCore/include/mhw_morph_identity.h)，SDK 内提供相同副本。通过动态查询导出 `MhwMorphGetAssetIdentity` 调用，传入扩展版本、输出结构大小和当前目标句柄。

原 `MhmApi` v1 布局、版本和 getter 保持兼容。未提供扩展的旧核心仍可使用普通面板控制，预设功能显示需要配套核心。未携带已验证摘要的旧式宿主目标返回 `MHM_NOT_READY`，已退役目标返回 `MHM_STALE`；失败不修改输出。扩展不接受客户端提供的摘要来替代核心已加载资产。

## 非界面验证

先运行 `tools/build_mhwi_equipmentmorph_current.ps1` 构建核心，再运行：

```powershell
./tools/build_mhwi_equipmentmorph_imgui.ps1 -CoreCandidate .build/cleanup-validation/native/MHWEquipmentMorphConfiguredPrototype.dll
```

构建只运行控制和预设的控制台回归；`-CoreCandidate` 另行核对实际 DLL 的旧 API 和身份扩展导出。它不会启动图形窗口或游戏。界面、手感及实机测试由用户执行。
