# 装备目录来源与重建

插件随附的 `equipment_catalog.json` 来自用户新提供的 `Book.xlsx`，提供者明确授权自由使用和再分发，不附加使用限制。旧受限制表格和旧目录没有用于此提取，也不包含在公开仓库或公开安装包中。目录使用授权与项目代码的GPL许可证分开说明。

源工作表为六列，无表头：部位、防具ID、部件名称、套装ID、男性装备目录、女性装备目录。源 `chest` 对应插件的 `body`；文本 `None` 表示该性别未提供目录。数据保留2896条部件记录和641个套装编号。套装搜索名称从同套装部件名称的共有前缀与共有等级后缀生成；只有单个部件时保留该部件全名。部件原名和ID始终保留，编号不同的条目不会合并。

头、身体、腕、腰、腿分别对应资源目录 helm、body、arm、wst、leg。完整模型路径由源男女目录和具体部位生成，再精确匹配用户自备解包目录中的 MOD3 文件名。5657条可用路径引用2391个模型文件；60条组合源文件未提供性别目录，75条组合未找到对应模型，不作为可选目标。只读取文件名，没有读取或发布游戏模型内容。每个部位的实际目录优先，保留特殊头部变体与共享资源。

源文件SHA256为 `9cf1db9cdc82f88fc77ead918b7311403ac30f9962d2e95b35df3ac4e6a0824a`，工作表为 Sheet1。仓库提供提取代码和生成目录，原始工作簿保持原样。需要重建时，在安装开发依赖后运行：

```powershell
python ./tools/build_equipment_catalog.py --source 'Book.xlsx' --pl-root '你的解包目录/chunk/pl' --output 'blender_addon_v044/mhwi_equipmentmorph/equipment_catalog.json'
```

提取会验证部位、ID、男女目录格式及重复记录；目录JSON保留源字段和源摘要。公开检查入口包含目录结构与装备选择回归。高级手动路径仍可使用，填写相对 nativePC 的完整路径，例如 `pl/f_equip/pl105_0000/body/mod/f_body105_0000`。
