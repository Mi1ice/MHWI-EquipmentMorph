# 0.6.0 发行说明

当前源码与组件包版本为0.6.0，正在准备发行。作者插件与独立作者工具保持0.4.4，SDK保持0.4.0。正式发行仍为v0.5.0；本说明不表示新版本已打标签或公开发布。

## 主要变化

- 增加可选的Dear ImGui游戏内面板。使用Del呼出，选择当前具有形态键数据的装备，按键调节、精确输入或释放控制；支持多个装备部位。
- 增加整套预设的保存、预览、筛选管理、回收与永久删除、导入和导出。编辑后手动保存，关闭面板恢复各部位已应用的预设；启动和换装后自动恢复。
- 提供持久捏人总开关、默认窗口布局、中文输入及装备名称／完整资源编号显示。界面外观仍可后续优化。
- 修正保持控制时的装备重新绑定与冗余运行开销；包含已结束的dev12性能优化。修正跨屏返回后的面板输入失配、显隐返回值造成的光标隐藏循环，以及相关风扇突增、闪烁和光标消失。
- 核心与面板分别为独立DLL。仅需API支持时安装核心；预设后台和界面功能由可选ImGui插件提供。Tauri与旧控制窗口源码作为历史保留，不进入本次组件包载荷。

## 附件与配置

本地交付包包含仅核心包、核心＋ImGui包、Blender插件0.4.4、独立作者工具0.4.4及绑定源码提交的源码归档。根目录同时提供SHA256SUMS.txt和发行候选清单。

安装前正常退出游戏。仅核心安装可升级添加面板；移除面板或从旧控制窗口整包切换时，先卸载原受管组件，再安装所需组合。公共runtime.ini来自运行时包根目录；作者工具、Blender插件和MOD不各自提供公共配置。

本次升级不保证开发测试期旧预设与配置兼容，不提供迁移器。当前JSON仍各自使用schema 1，继续严格核验资源路径、MOD3与形态键包指纹。安装器不转换或删除用户数据；保留文件不代表旧格式必然可读。

## 验证与合并范围

核心、输入、控制、预设、SDK与合成目录安装检查已通过。用户已确认预设和多部位控制、中文输入及跨屏问题修正；最新光标返回值修正消除了风扇突增、闪烁和光标消失。构建脚本不运行图形测试，游戏内验证由用户完成。

已测试核心和ImGui载荷的摘要与最近本地构建一致。新组件安装器已在合成目录完成安装、升级、回退、卸载和冲突测试；尚未将本地发行包作为正式版本发布。候选清单保留formal_acceptance_complete=false，不自动扩大为所有环境的实机验收。

本轮变更通过[PR #2](https://github.com/Mi1ice/MHWI-EquipmentMorph/pull/2)合入main。合并包含核心身份查询扩展、面板与预设、输入修正、组件安装和配套文档；保留暂停的Tauri源码与固定依赖资料，生成包和私人日志／模型不进入源码提交。发布前核对准确的来源提交、附件清单和校验值，再创建相应标签与发行。
