# C03 数值验收规则

2026-10-27，用户已明确批准本轮提案并要求执行最终判定。规则版本：`mhwi-c03-approved-rule-v1`。本规则的已验收应用范围是本轮冻结的489键配对数据、BASELINE／GEOMETRIC两模式及4932个已绑定案例；不是所有模型、格式、组合或负载的通用精度保证。

## 位置判据

对每个案例、每个序列化顶点，在同一MOD3导出坐标域比较运行时与Blender参考：

`max_v sqrt((x_runtime-x_ref)^2 + (y_runtime-y_ref)^2 + (z_runtime-z_ref)^2) <= 0.0005`。

单位为MOD3导出坐标单位，不能直接解释成物理毫米／米。边界包含等号；近零位置或近零形变量也用同一绝对规则，不除以坐标或位移。mean、RMS、P50／P95／P99用于解释分布，不能覆盖某个顶点超限。权重的支持范围仍为0～1；五档数值采样不是产品输入档位限制。

本轮依据是冻结输入的基准／增量编码误差，加上按顶点实际参与数推导的运行时与条件性源坐标float32舍入预算，总计约`0.000406868358`，向上取`0.0001`档得到`0.0005`。它不是观察最大值的任意倍数，也不替代无可见差异要求。

## 独立硬条件

- 全零权重时，输出与该配对包基准逐字节一致。
- 模型、包、profile、trace、参考、源码／工具及案例清单身份有效，摘要与批准记录一致；案例及顶点追溯完整。
- 参考／合成结果和报告有限，单位明确。缺批准、缺文件、摘要漂移、错误单位或缺案例不得得到passed。
- 声明允许的位置／既有方向字段以外的字节保持不变。
- 对照Blender无可见差异。视觉结果由对应的用户观察单独提供，判定工具不生成视觉通过结论。

法线／切线继续采用既有算法、量化及已批准异常策略，不新增所有组合逐帧与Blender方向相等的要求。

## 冻结案例与适用性

每模式489键、30983个序列化顶点、2466案例：基准1个，所有键的0／0.25／0.5／0.75／1单键点2445个，两组代表组合／重置20个。每模式492个全零案例。代表组合最多30键非零，任一顶点实际非零增量数最大30，最差点21。模型包围盒约`148.58636×166.44023×26.99538`，参考／合成坐标分量绝对值小于100。

正式应用只覆盖批准记录所绑定的冻结输入／案例及当前测量路径。旧参考不自动认证当前新导出的15键资产；相近尺度或负载本身不等于新资产已认证。任意489键组合、1024键压力、其他尺度／布局、新作者资产、游戏浮点环境、GPU、性能与发布均不由本次结论保证。

原用户视觉报告是两模式各25个批准案例的汇总结果。资产和权重身份已与本次数值输入对应；它不是全部489键的逐项视觉检查，也不改写为新的实机测量。

## 离线判定工具

`tools/check_morph_numerical_acceptance.py`读取批准记录、原提案、输入／来源审计、真实生产比较器的报告及其SHA-256绑定；校验当前被测生产头文件和比较器身份，逐案例检查最大误差和硬条件。它不调用Blender、游戏、Compose、导出器或部署操作。

用法：`python tools/check_morph_numerical_acceptance.py --root <证据工作区> --rule <approved-rule.json> --output <新的结果文件.json>`。

`approved-rule.json`必须为approved状态，引用直接用户批准记录，且后者的提案摘要和具体指标／单位／上限一致。所有引用输入都必须位于显式root内并有摘要绑定。工具只创建新的结果文件，拒绝覆盖既有文件。

退出0表示本次绑定案例数值passed；退出1表示至少一个案例的位置误差超限；退出2表示批准、输入或硬条件无效，拒绝出具通过报告。输出只判断数值及所绑定硬条件，不独立宣布项目完成、视觉通过或发布。

私人输入、批准原文和最终案例报告保存在本地工作区证据中，不随产品文档内嵌。复制此规则文档不等于复制了对应批准／输入身份，不能据此认证其他数据。
