# 联合导出的作者角点法线与切线

联合导出在临时求值克隆中保存拆点前的作者角点法线、角点编号、原顶点和第一套UV。现有编辑器完成UV／锐边拆点与三角化后，作者法线按逆转置变换到最终模型坐标；不再把编辑器重新编码的自定义法线当作最终作者方向。

切线使用固定Blender5.1.2的MikkTSpace源码，直接接收最终坐标、UV和作者角点方向。计算采用串行路径，避免并行归约改变临界编码。输出切线在精确作者方向上投影并归一化；保留Mikk的手性。若切线组抵消但该三角形仍有明确的U微分，使用该角点的三角形微分并记录原因；若微分也无定义则拒绝，不指定任意轴。

同一个导出顶点不能存储不同角点的法线／切线。适配器按最终实际编码保留这些接缝，仅在导出克隆拆点，并校验面集合／绕序、坐标、UV、颜色、绑定与源索引不变。源工程及形态键不保存或改写。序列化顶点数可能增加，这是导出接缝的显式表示，不是新增源网格形状。

GEOMETRIC端点仍在额外接缝拆点前的网格上计算，通过最终角点追溯到序列化顶点，避免切线接缝改变几何平滑扇区。原有无定义／反向端点的独立显式基准规则与默认拒绝保持不变。包格式和运行时合成算法没有改动。本修复保证配对基准的作者角点法线与最终切线；形态键变化后的切线继续遵循既有运行时方向合成，不会按变形后UV微分逐帧重算，实际材质效果仍需视觉验收。

## 构建与分发

Windows x64源码构建先运行 `./tools/build_authored_shading.ps1`。编译所需MSVC／Windows SDK与现有核心构建相同。输出是作者插件内的独立计算组件，带版本、摘要、源文件摘要和许可证清单；不进入`nativePC/plugins`，不安装游戏组件。源码与原版Apache-2.0许可证位于 `research/blender-mikktspace-5.1.2/`，薄封装位于 `native/author_shading.cpp`。

容量Paired／All及完整源码入口会先构建计算组件。作者ZIP仅包含当前清单指向的组件、清单及许可证，不夹带旧计算组件；缺少组件、摘要不匹配或缺少归属说明时拒绝打包。安装完整作者ZIP不要求用户在自己的电脑上编译。直接复制未构建的作者源码不是完整插件分发。

`tools/test_authored_shading_blender.py`独立核对平面已知方向、作者角点与UV、镜像／非均匀变换、手性、组抵消、无效角点／UV及失败后清理；`tools/test_authored_shading_package.py`在隔离目录核对ZIP与组件。原有容量、导出、预览、法线规则和宿主回归继续执行。

编码后的法线／切线受有符号8位量化影响，测试使用编码舍入可推导的边界，不以新数值容差代替模型／游戏验收。真实素材重新导出必须使用新模型、profile与pack的完整配对；旧模型不能混用新包。软件检查不授予视觉或性能验收。
