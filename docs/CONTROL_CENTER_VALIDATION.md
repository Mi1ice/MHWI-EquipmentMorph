日期：2026-10-19。候选：`0.5.1-dev12-controlcenter-dev1`，控制中心 0.2.0，运行时核心 dev12。此页只记录软件验证，不代表游戏或 GPU 实机验收。

## 已完成

- 11 项浏览器交互检查：连续精度输入、零权重接管、逐键／全部释放、无效输入保留贡献、装备选择、搜索、断线、冲突、64 键及窄窗口布局和数字对齐。
- 7 项 Rust 后端检查：协议字节布局、64 位标识及 float32 精度、非法响应、断线代际和操作清空、关闭释放。
- 15 项控制会话、29 项实际管道、12 项兼容原生窗口及 5 项启动计划检查。
- 39 项模拟安装检查，包括三文件升级为四文件、回滚、卸载、配置及用户包保留、未知文件拒绝、已知旧文件接管恢复、损坏包、路径穿越、目录连接和并发安装。
- Tauri 生产构建已生成，可使用本地 WebView2 运行。依赖版本和声明随候选包提供。

软件联动使用明确标为“无游戏/GPU”的模拟窗口，加载生产桥接和隔离 CPU 软件核心，过程由实际 Tauri 窗口操作：后台自动启动，Ctrl＋Shift＋M 呼出，设置 `0.432198`，隐藏超过租约超时时间后贡献仍为原值，再次呼出状态保留；“×”隐藏后，软件核心中的 requested 和 source 均为 0。最终构建另验证 `0.6` 在最小化约 20 秒后保留，快捷键一次恢复；模拟游戏正常退出后控制程序退出。模拟核心未发布 GPU 帧，applied 保持 0，不能据此验证游戏形变或平滑效果。

受限桌面测试进程最初出现快捷键注册失败，正常桌面权限下复测成功。程序现显示实际注册错误，避免把权限失败统一解释为快捷键占用。

## 界面决策与检查

按 design-taste-frontend 的应用界面流程采用 Achromatic ledger，seed `1694937840`。保留中文系统字体 Microsoft YaHei UI／Segoe UI。将抽取的图标侧栏重抽为 No sidebar：本窗口只有一个工作目的，没有可用的侧栏目的地。唯一数据色用于已应用权重和滑块；模型完整路径、逐键控制来源和目标／应用值是此项目的识别信息。

窗口回答的问题是“当前装备有哪些形态键，由谁接管，实际应用了多少”。列表和编辑区共享页面边缘；数字右对齐、使用等宽数字；零值明确显示为 0，缺失选择显示破折号。检查了 1440、768、390 三种浏览器尺寸及真实桌面窗口。应用最小宽度为 680，390 尺寸仅为防溢出的额外检查，表格在自身区域横向滚动。

浏览器检查器最终 0 FAIL、0 WARN；允许 `ragged-row`：列表随实际键数增长，详情区按编辑内容定高，避免为了对齐而拉长三行数据制造空白。第一轮发现的过小文字和窄屏编辑区裁切已修正；最终各尺寸编辑按钮可见，页面无横向溢出。没有为装饰填充空列表或添加虚构统计。

开发预览中 pl001 身体／腰部、vrc.blink／smile／cheek／adjust、PID 4242 和大整数句柄均为显式合成数据；生产模式关闭预览入口，数据来自现有桥接。
