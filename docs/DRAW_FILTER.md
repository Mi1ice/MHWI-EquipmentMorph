# 0.5.1-dev12 无关绘制回调早退

用户确认dev11实机按0→0.01→1→0约为200→180→180→200 FPS，调节、释放和换装重绑正常。日志确认固定非零期间没有重复形变上传，但每秒约45万次无关draw回调仍取得同一把gate，平均等锁从约0.72升到2.85微秒。dev12先减少这些无关回调的锁竞争，目标装备的非零校验与形变路径保持原样，GPU耗时仍未采集。

## 行为与并发边界

仅kind=2的draw入口增加地址预筛选，直接使用寄存器中的owner数值，不解引用owner，不读取游戏内存或计时时钟。筛选拒绝时保持所有输入寄存器原值并返回；compute与dispatch入口保持原流程。

筛选使用一个确认无锁的64位原子掩码，每个owner映射为两个位置。在RefreshMainPlayer持有gate期间，先以原子或操作登记候选owners，再发布权威mainPlayerOwners。筛选位只增加，不清空、不移除旧地址；因此旧地址、碰撞和累计饱和都会进入原有锁内校验。不能在生产运行中重置该掩码。

首次绑定仍须经过已登记owner的捕获、资源发布和原生边界证明。预筛选肯定结果不授权替换：回调随后仍取得gate，核对当前armed/player/owner路由，执行原有身份、代际、选择、资源合约与提交校验。换装、玩家移除或地址重用后，历史掩码不会使过期owner重新生效。空owner也保留原有路径。

长时间运行若历史地址填满掩码，性能收益可能减小，最终回退为既有锁内路径；不会因此放宽资源与生命周期校验。本版不通过在锁外直接读取可变的mainPlayerOwners数组实现早退。

## 日志变化

input_timing_window仅统计实际进入gate路径的回调，早退数量不再包含在other桶内。因此不能把本版other.calls减少理解为游戏绘制量下降，也不能直接与dev11的other平均耗时作为同一总体比较。

新增draw_filter_window事件，在工作线程既有计时输出点于锁外记录：

- bypassed_calls_reported：进程累计已上报早退数，不是本窗口精确调用数。
- batch_size=256，unreported_per_thread_max=255：每线程先累计，满256次才更新一次共享原子计数，避免每次无关draw都争抢另一计数器。线程退出时不足一批的尾数不补报；相邻窗口差分也有批次跨窗误差。
- mask_set_bits：掩码当前已置位数量，最大64。它是碰撞与饱和程度的线索，不是owner数量。
- counter_saturated：累计计数是否饱和；不会数值回绕。

早退回调只做地址哈希、一次原子掩码读取、线程局部计数，以及每256次一次批量原子累加；不记录文件、不分配内存、不取得gate。命中筛选的目标保持原有约1/64抽样计时。

同时修复dev11诊断首个窗口的时钟域：窗口起点现在从与主循环一致的相对QPC毫秒0开始，满1秒才输出，不再混用GetTickCount64的系统运行时间。后续窗口保留经过时间和倒退检查。日志仍无逐事件墙钟时间，实机对比请记录各段大致起止时间。

## 软件验证

先在dev11生产Input上复现“gate被占用时无关draw无法返回”，新增测试失败后才实现早退。新增29项原生回归，完整原生共636项，涵盖：实际回调锁阻塞、零值与非零读取次数、早退不读取QPC/游戏内存、碰撞与饱和回退、旧路由拒绝、并发模型替换、生产RefreshMainPlayer发布、新旧玩家切换、原子登记不丢位、分批遥测、计数饱和和首个诊断窗口。原有并发输入、重绑、上传与退役回归保留。

合成对照使用同一生产Input，比较启用和编译时禁用筛选，每线程8000组，一组包含70次无关draw及1次身体draw，分别以1/4线程重复五轮交替运行。无关调用不发生地址碰撞；碰撞安全性由独立回归覆盖。该负载模拟日志中调用量比例，不等同于游戏线程调度或GPU工作，结果不承诺实机FPS收益。

## 实机测试

正常退出游戏及控制窗口后通过本候选包安装入口更新，保留已有公共runtime.ini。包顶层runtime.ini来自仓库config/runtime.ini，是空配置模板；用户MOD旁的.morph和现有公共配置继续使用。包内附带本说明及原输入诊断说明。

在同一场景、镜头和画质下按0→0.01→1→0各停留约30秒，固定非零时停止拖动，记录大致帧率和起止时间。然后检查连续调节、反向、释放，以及保持控制的001→其它套装→001重新绑定。

2026-10-19用户已确认dev12调节、释放及保持控制的换装重绑通过，并补测多个部位同时非零，反馈帧率略有降低，明确结束本轮性能优化。本轮七段PresentMon对照约为零值205.14 FPS、非零202.24 FPS；没有观察到GPUBusy增长，CPU/GPU百分比归因仍未完成。当前保留dev12开发基线，详见[验证结论](DEV12_BASELINE.md)。正式0.5.0发行附件保持不变。
