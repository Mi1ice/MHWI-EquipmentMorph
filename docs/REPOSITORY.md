# 项目结构与来源

- `blender_addon_v044/`：当前作者插件与标准库导出后端。
- `runtime/`：形态键核心、模型目录、自动绑定、桥接和必要兼容头文件。
- `diagnostics/EquipmentMorphDiskContract/`：当前生产宿主与原生回归。名称沿用开发工程，目录内宿主仍是实际运行时。
- `diagnostics/`下另外四个头文件：生产宿主直接依赖的构建保护与退役边界，按原路径保留。
- `controls/`：手动控制窗口源码与测试。
- `sdk/`：公开ABI、客户端封装和示例。
- `tools/`：便携构建、合成验证、打包、资源ID迁移和配对MOD安装工具。
- `installer/`：运行时事务安装器模板。
- `config/`：当前源码版本及format=2空配置。
- `research/safetyhook-local-v0.7.0/`：固定版本依赖源码和许可证。
- `docs/`：面向使用者与开发者的当前说明。

此仓库最初由原项目源码独立整理，不包含原项目Git历史；当前默认分支main继续维护开发源码，已合入dev12重绑修复与性能优化。版本关系见[项目状态](PROJECT_STATUS.md)。旧作者插件、重复发行包、早期探针、游戏采样、私人验收收据及用户MOD不纳入公开树。首次整理时生产源码按原路径和原字节复制；后续修订由此仓库的Git历史记录。构建入口发现本机工具链，打包入口只依赖当前源码构建。

不要按目录旧名称删除必需头文件，或直接将单模型配置用于format=2运行时。对源码、协议和安装工具的修改应在对应回归通过后提交。
