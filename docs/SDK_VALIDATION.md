# 独立SDK现场对照工具

这是供明确案例逐项观察的独立应用，不依赖旧面板。它在普通线程中取得已经加载核心的公开SDK和资源身份扩展，提供独立Win32桌面窗口，不增加游戏内绘制或输入钩子。核心、数据格式和来源仲裁语义保持不变；它不自动作出视觉验收结论。

## 构建与输入

在Windows x64/MSVC环境运行：

```powershell
./tools/check_sdk_validation.ps1 -Stage All -Python <python.exe>
```

输出位于`.build/sdk-validation/`。自动检查只使用合成核心与无窗口模型，不启动DLL、游戏或Blender。`Cases`检查案例解码与转换，`Sdk`检查实际SDK会话及现有SDK回归，`Controller`检查操作和窗口模型，`Build`编译四组检查与DLL；`All`执行全部阶段并生成来源／产物摘要报告。

DLL名为`MHWEquipmentMorphSdkValidation.dll`，案例文件固定为邻接的`MHWEquipmentMorphSdkValidation.cases.json`。操作记录放在邻接`MHWEquipmentMorphSdkValidation.logs/`，每次会话新建UTF-8 JSONL文件，单文件32MiB，不能写入或达到上限时停止新案例／非零步骤，保留归零和结束。源文件及通用测试不包含实际模型或私人键名。

案例格式`mhwi-sdk-validation-catalog-v1`包含身体目标模型ID、预期实际键数、BASELINE和GEOMETRIC的模型／包SHA256、所需ASCII ID与完整UTF-8源名标签、小规模案例及九步权重曲线。标签使用小数组，完整目标键表由SDK发现；每次提交按实际目标数量构造完整权重向量，未参与项也明确为0。文件读取上限256KiB，未知／重复字段、无效UTF-8、坏身份或不完整案例均拒绝。

准备工具只读转换外部案例及两份配对参考：

```powershell
python ./tools/prepare_sdk_validation_catalog.py --cases <proposal.json> --baseline-reference <reference.json> --geometric-reference <reference.json> --output <new-catalog.json>
```

输出必须是新文件；两模式映射、源名、资源摘要和组合权重必须一致。当前加载的目标身份来自公开扩展，不根据磁盘后来替换的文件、名称或键数猜测模式。缺少身份查询时拒绝控制。

## 操作与状态

启动只发现并显示资源，不自动提交。点击“开始本例”才施加当前案例；来源普通优先级200、租约2000毫秒，约500毫秒续租。窗口失焦、切到Blender或最小化继续保持当前形变和续租，不自动推进权重。

变化键通过按钮按`0,.25,.5,.75,1,.75,.5,.25,0`前后移动，可以重复当前步骤。组合有25键固定0.5、5键共同变化，因此组合最后一步仍保留25键0.5；“全部归零”才将身体目标的所有动态键置0，并保持本工具来源。

上一例／下一例先请求全部归零，核心确认之后才选择相邻案例，随后等待手动开始。等待操作期间不接受另一条非零命令，仍可归零或结束。标题关闭按钮和“结束”走同一流程：取消尚未处理的非零命令、确认全部归零，再释放自身来源；释放后其他来源可能重新生效。无法确认时明确显示归零未确认并释放自身来源，不承诺结束后仍为零。

“已提交”仅表示API接受；“核心报告已应用”还核对同目标代次及资源身份、完整请求／应用权重、每键来源均为本工具，以及该目标应用修订不早于提交。全局请求修订不作为单目标应用收据。相同数值被其他来源覆盖也不能视为本工具已应用。换装、退役、租约失败或身份变化中止当前案例，不自动重放到新目标；重新识别后需要手动开始。

窗口提供完整源名、ID、固定／变化及权重的可滚动只读文本，可选中复制。使用系统按钮、焦点与Tab导航；全屏游戏需要切换到独立窗口。窗口结束后本次插件会话结束；重新打开通常需要重启游戏，不提供新快捷键、托盘或动态重载入口。

## 交付与待测范围

通用打包工具只组装新插件、邻接案例、说明、报告及摘要；核心与配对模型／包是既有依赖，不包含替换载荷或自动部署入口。私人案例只能在独立私人候选中配套。

软件检查不等于DLL已经部署、实际SDK已经连接、原生窗口体验或动态形变已经验收。实际操作需另行确认游戏观察场景、其他控制来源及部署安排，并核对当前核心与加载资产；用户本人现场操作Blender副本，不自动设置或保存工程。正式面板、预设和自动表情容量适配、五部位生命周期、数值容差及性能验收继续独立推进。
