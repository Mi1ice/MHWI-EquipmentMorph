# dev12 开发基线与本轮性能验证

2026-10-19，用户确认 dev12 的形态键调节、释放恢复及保持控制的换装重绑正常，并补测多个部位同时非零，反馈帧率略有降低，明确结束本轮性能优化。当前保留 `0.5.1-dev12-source` 作为开发基线；正式 `0.5.0` 标签和发行附件保持原样。

dev12 在取得运行时 gate 前筛掉无关绘制 owner，保留目标装备的身份、新鲜性、代际及 GPU 退役保护。原生软件检查共636项；诊断记录表明无关绘制早退已生效，目标回调的等待锁耗时降低。详见[实现与边界](DRAW_FILTER.md)。

用户提供了七段同场景 PresentMon 录制，权重0与1交替，其它设置保持一致。按各段中间20秒、相邻零值录制配对，零值平均约205.14 FPS，非零约202.24 FPS，平均额外帧间隔约0.071毫秒。三组均未观察到 GPUBusy 增长，GPUTime 的差异主要出现在等待项；不能据此将插件开销归因为CPU百分比或GPU百分比，也不证明GPU成本为零。

这里只有三段非零录制，硬件频率、温度和HAGS状态未核实，未采集CPU调用栈与调度证据。多部位非零补测没有提供精确FPS。因此保留轻微非零帧率开销这一已知限制，不把单场景结果推广为所有装备和硬件的性能保证。

原始用户采样、私人日志和本机路径不进入公开仓库。此说明同步已有验收与分析结论，没有启动新的性能采集，也没有扩大正式0.5.0二进制的验收范围。本轮没有待完成的性能优化任务；完整MOD压缩包换装工具仍按此前决定暂缓。
