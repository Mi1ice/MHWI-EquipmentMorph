## 当前功能

按 Del 呼出面板，支持中文输入、装备及多部位形态键调节、整套预设保存、筛选管理、回收和永久删除、导入／导出。选择预设立即预览，编辑后手动保存；关闭面板结束预览并恢复各部位已应用的预设，未保存时确认保存、放弃或取消。

“应用预设”建立启动／换装自动应用关联，“取消应用”移除关联。“启用形态键控制”持久开关只影响形态键控制模块，其他插件仍可使用核心 API。每次启动使用默认窗口布局，显式零权重接管及逐键复选框保留。详见[预设说明](PRESETS.md)。

仅核心与核心＋ImGui包分别安装独立组件，不安装旧控制桥接或窗口 EXE。公共 `runtime.ini` 随运行包提供。安装器支持添加面板、回退与卸载，拒绝覆盖未知新增组件；见[安装说明](IMGUI_INSTALLATION.md)。

本次升级不承诺兼容开发测试期的旧预设与配置，不提供迁移器。三类 JSON 各自严格接受 `schema: 1`，资源路径、MOD3 和形态键包身份校验继续保留。安装器不转换或删除用户数据。

## 验证结论

用户已确认调节、多部位控制、预设与自动恢复、中文输入正常。跨屏返回后面板无响应由物理鼠标状态补偿修正；随后 `c5c1b8d` 的光标显隐返回值修正消除了风扇突增、闪烁和光标消失。采样曾显示窗口线程约5秒占满一个逻辑核心，GPU功耗未增加；未采集现场调用栈，保留该归因边界，见[输入修正说明](INPUT_HANDOFF.md)。

完整 ImGui 软件入口通过643项核心、99项输入、33项控制、309项预设、14项 SDK、26项作者后端及29项组件安装检查；共享安装器原有29项检查也通过。核心与面板载荷可通过摘要与用户已测版本核对，构建清单的 `formal_acceptance_complete` 不自动改为 true。图形及游戏测试由用户执行，组件安装检查使用合成目录。详见[验证范围](VALIDATION.md)。

dev12 调节、释放和保持控制的换装重绑、多部位非零均已通过用户测试，本轮性能优化结束。非零仍有轻微帧率开销；同场景采样与 CPU/GPU 归因限制见[dev12 基线](DEV12_BASELINE.md)。历史 dev1 至 dev11 文档和候选状态保留，不代表当前需要重做整轮测试。
