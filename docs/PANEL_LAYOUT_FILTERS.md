# 面板布局与形态键筛选候选

本分支基于已发布0.6.0增加布局、筛选和反馈整理。用户已确认layout-filter-dev1新增功能测试通过；dev2仅补充管理按钮的打开／收起行为，尚待确认。该候选不改变核心、输入钩子、平滑、预设存储或关闭预览规则。

## 主窗口

预设选择、保存、另存为、管理和总开关集中在上方，空间不足时换行；自动应用关联另成一行。“各部位当前配置”直接展开，长内容换行以保留完整资源编号。装备与形态键表格使用其余空间，表头固定。

## 形态键筛选

搜索忽略首尾ASCII空白及英文字母大小写，支持中文原文包含匹配。搜索与以下状态取交集：

- 全部。
- 已接管：本面板持有贡献，包含零权重。
- 未接管：本面板没有贡献，其他来源仍可能控制此键。
- 非零（本面板）：已接管且目标权重不为零，保留原float精度；不依据平滑中的实际权重。

正在拖动／输入和等待提交确认的行暂时保留，操作结束并确认提交后才隐藏。筛选仅作用于当前装备的显示，不释放权重，不改变保存当前／另存为的完整控制数据，也不重排键顺序。

同一装备内关闭再打开保留条件；切换部位、换装导致目标改变或重启时恢复全部。无结果可清除筛选。关闭捏人后仍可浏览装备与筛选，权重调节和预览继续禁用。

## 管理侧栏与反馈

管理仍位于主窗口右侧、等高并支持拖动右边缘调宽。主窗口“管理…”打开侧栏，打开后按钮显示“收起管理”，再次点击关闭侧栏；标题栏×仍可关闭。此操作不保存、放弃或释放当前权重与预览。“全部预设／回收区”改用页签，搜索与匹配筛选集中显示。内容宽度至少600时左右排列列表与详情，较窄时上下排列；此断点仍需用户验证中文与实际窗口尺寸。

成功消息显示3秒，错误保留；同一操作结果避免在主窗口、管理和导入弹窗同时重复显示。原有永久删除确认、未保存确认和失败保护继续保留。

## 验证范围

新增无窗口检查覆盖零接管、极小非零、负值、中文与大小写搜索、筛选交集、操作中保留行、换装重置、筛选后的原键编号以及隐藏行仍保留完整控制数据。构建图形测试程序但不启动；界面与游戏测试由用户执行。

建议实测：全部四种筛选、非零中拖至零、精确输入、筛选后保存整套预设、切换装备重置条件、关闭／重新打开、总开关、未保存确认，以及管理侧栏缩窄与调宽。
